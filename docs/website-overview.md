## Product and support status

Linux x86_64 Debian packages are the production target. Windows and Intel macOS have portability and unsigned-packaging checks, not production downloads. Source versions and release candidates are distinct from published production assets.

Active feature development is ending after the next verified release; the repository may be archived afterward. No ongoing maintenance or security-response commitment is offered. See the canonical [README](../README.md).
